\section{Independence of Held-Out Drawings}
\label{sec:split-limitations}
% source: docs/decisions/0006-floorplancad-split-by-source-group.md
The overlap found in the official release folders makes source grouping part of
the experimental method, since an evaluation based on those folders would not
have the source separation required here.
% source: docs/decisions/0006-floorplancad-split-by-source-group.md
Removing exact copies addresses identical content, while keeping complete source
groups together addresses the relation between crops attributed to a common
source under the adopted naming convention.
% source: docs/decisions/0006-floorplancad-split-by-source-group.md
Neither check identifies every possible near-duplicate crop.

% source: docs/decisions/0007-floorplancad-fold-assignment.md
The assignment is also not stratified by class, and keeping groups intact can
cause fold sizes to exceed their target fractions.
% source: runs/2026-10-26-floorplancad-split/metrics.json
The class counts provide a description of the resulting partition, rather than
evidence that the folds have identical class composition.
% source: docs/decisions/0007-floorplancad-fold-assignment.md
Any change to that partition requires a new recorded split, preserving the
meaning of comparisons made under the existing assignment.

\section{Reference Labels and Metric Interpretation}
\label{sec:label-metric-limitations}
% source: docs/decisions/0005-floorplancad-class-mapping.md
The wall mapping is supported by layer associations, whereas the adopted door
and window assignments also depend on visual inspection where shared layers fail
to separate the classes.
% source: docs/decisions/0005-floorplancad-class-mapping.md
This evidence identifies a release convention without verifying every reference
label, and the uncertain sliding-door assignment remains a limitation.
% source: docs/decisions/0005-floorplancad-class-mapping.md
The exclusion of curtain walls also fixes the current meaning of the wall target.

% source: docs/decisions/0009-element-metrics.md
Pooled scoring weights each entity equally, so drawings containing more scored
geometry contribute more to the resulting class counts than smaller drawings.
% source: docs/decisions/0009-element-metrics.md
Per-drawing scores can supplement this view, but the primary precision, recall
and \(F\)-score remain defined over the pooled held-out entities.
% source: docs/decisions/0009-element-metrics.md
The raster-to-vector mapping is part of the evaluated method because it determines
which entity predictions enter those counts.
