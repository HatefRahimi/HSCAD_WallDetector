\bfseries
% Abstract in English
{\selectlanguage{english}Abstract}
\normalfont
\end{center}

% source: docs/decisions/0010-evidence-backed-thesis-draft.md
This thesis investigates the recognition of semantic classes in industrial vector
floor-plan drawings, with walls as the primary target and doors and windows as
secondary targets.
% source: docs/decisions/0008-floorplancad-only-training.md
The experimental design uses FloorPlanCAD as the sole training source and reserves
industrial drawings for external evaluation after conversion into a compatible
representation.
% source: docs/decisions/0009-element-metrics.md
Vector and raster methods are to be compared using precision, recall and the
harmonic-mean \(F\)-score over held-out geometric entities, requiring raster
predictions to be mapped back to those entities before scoring.
% source: docs/decisions/0005-floorplancad-class-mapping.md
% source: docs/decisions/0006-floorplancad-split-by-source-group.md
The completed data audits establish a release-specific class interpretation and
identify exact duplicates and source overlap across the official release folders.
% source: docs/decisions/0007-floorplancad-fold-assignment.md
A separate source-group split is frozen for subsequent experiments.
% source: docs/decisions/0010-evidence-backed-thesis-draft.md
The present draft reports these data findings and the evaluation design; model
performance, learning without layer names, industrial transfer and valid wall
generation remain to be measured.
